## スマホ向けバスドラム (kick-mid-1/2)

スマホのスピーカーは 100Hz 以下がほとんど鳴らないため、kick-1/2 の元ミックスに
倍音付加 (tanh ソフトクリップ)・60Hz 付近のカット・250Hz / 1.2kHz / 3.5kHz の持ち上げを行い、
150Hz〜5kHz 帯の音量を約 10dB 上げたものです。設定パネルの
「バスドラムをスマホでも聞こえやすく」(初期値オン) で切り替えられます。
