## スマホ向けバスドラム (kick-mid-1/2)

スマホのスピーカーは 100Hz 以下がほとんど鳴らないため、録音の段階で中域が多く入っている
オーバーヘッド・ミッド・ルームのマイクを主体に、キックの近接マイクを少し混ぜて作っています
(kick_snon_vl3_rr1/rr2 の kickmic 0.4 / oh 1.0 / room 0.5 / mid 0.5)。
歪みは加えず、110Hz 以下のカット、190Hz と 3.2kHz の持ち上げ、軽いコンプレッサーのみです。
150Hz〜5kHz 帯の音量は録音そのままの kick-1/2 より約 10dB 大きくなります。
設定パネルの「バスドラムをスマホでも聞こえやすく」(初期値オン) で切り替えられます。
