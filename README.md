# 🥁 Drum Level Up — ドラム上達ゲーム

フレーズを楽譜で見ながらメトロノームに合わせて叩き、マイクで録音すると採点される、ドラム上達用の Web アプリです。
録音はフレーズごとに保存され、点数の推移やレベルで上達が分かります。譜面の作成や PDF の読み取りにも対応しています。
ブラウザだけで動作し、録音や PDF はどこにもアップロードされません。

## できること

### ドラム上達ゲーム (ホーム)
- **フレーズ集**: 基本ビート・バスドラムのバリエーション・16ビート・シンコペーション・フィルイン・手足の基礎 (24 フレーズ、Lv1〜4)。
  作ったフレーズや PDF から取り込んだ譜面も「マイフレーズ」として練習できます
- **楽譜表示とテンポ調節**: フレーズを楽譜で表示、30〜300 BPM。「手本を聴く」で生ドラムの音で確認
- **録音と採点**: マイクで録音し、叩いた瞬間を検出して手本と比べ、Perfect / Great / Good / Miss で採点 (100点満点、S〜D ランク、★1〜3)。
  走り気味/もたり気味の傾向、ばらつき、1音ずつのずれを表示し、楽譜の上にも判定を表示
- **録音の保存と成長の記録**: フレーズごとに録音を何回でも保存 (ブラウザ内の IndexedDB)。点数の推移グラフ、録音の聞き返し、自己ベスト・レベルアップ表示。
  録音するたびに経験値 (点数 × テンポ) がたまり、プレイヤーレベルが上がります
- **メトロノーム**: 鳴らすかどうか、録音に一緒に入れるかどうかを選べます。録音前に1小節のカウント
- **フレーズをずらす**: 全体または楽器ごとに 16分 / 8分 / 4分 / 32分 単位で前後にずらして新しいパターンを作り、マイフレーズに保存
- **フレーズ集の読み込み**: フレーズ集ファイル (JSON) を「フレーズ集を読み込む」で取り込むと、グループごとにホームに並びます。
  ファイルはこの端末のブラウザにだけ保存され、公開されません。形式は `src/game/pack.js` の先頭を参照
- **タイミング補正**: クリックに合わせて8回叩くと、マイクと音の遅れを計って採点を補正 (イヤホン使用時/スピーカー使用時で別々に保存)

### 譜面の作成・PDF 読み取り
- **作成モード**: マス目 (16分・8分・3連符・32分) をクリック/ドラッグして打ち込むと、ドラム譜が自動で描かれ、その通りに鳴ります。
  小節の複製・追加・削除、コピー&貼り付け、元に戻す/やり直し (Ctrl+Z / Ctrl+Shift+Z)。作った譜面はブラウザに自動保存され、ホームの一覧から開けます
- **PDF の自動認識 (ベータ)**: 5線のドラム譜から小節線・符頭 (●/×/○) を検出し、五線上の位置から楽器を、音符の間隔から拍位置を推定します
- **生ドラムの音で再生**: 実際のドラムセットを録音した [Virtuosity Drums](https://github.com/sfzinstruments/virtuosity_drums) (CC0) の音源を使用。再生位置は楽譜上にカーソルで表示
- **テンポ変更**: 30〜300 BPM。PDF のテンポ表記 (♩=92 など) を読み取り、50% / 75% / 100% ワンタッチ
- **区間ループ**: 楽譜上の小節をドラッグ (または Shift+クリック) で範囲指定。ループのたびにテンポを少しずつ上げる練習モードあり
- **ミキサー**: 楽器ごとの音量とミュート (自分が叩くパートを消してマイナスワン練習)
- **メトロノーム / カウントイン**
- PDF の読み取り結果は「この譜面を編集」で作成モードに取り込み、違うところを直せます
- テンポ・ループ範囲の設定は PDF / 譜面ごとにブラウザへ保存され、次に開くと復元

### キーボード操作

| キー | 動作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| ← / → | 前 / 次の小節 |
| ↑ / ↓ | テンポ ±1 |
| L | ループ ON/OFF |

## 認識について

- MuseScore・Finale・Sibelius・Dorico・LilyPond などから**書き出した PDF** を想定しています。スキャン画像や手書き譜は精度が落ちます。
- 楽器の配置は一般的な記譜 (HH = 第5線の上、ライド = 第5線、クラッシュ = 上第1線、スネア = 第3間、バスドラ = 第1間 など) を初期値にしています。
  楽譜によって書き方が違う場合は「認識の設定」の対応表で直すと全小節に反映されます。
- 拍子は自動判定しないので、4/4 以外は「認識の設定」で選んでください。
- 反復記号 (リピート・D.S.・コーダ) は展開しません。楽譜に書かれた順に再生します。
- 装飾音・アクセント・オープンハイハットの「o」などの記号は今のところ読み取りません。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 認識エンジン・シーケンサー・採点まわりのテスト
npm run build    # dist/ に静的ファイルを出力
```

`samples/*.ly` は LilyPond で作ったテスト用の譜面です (`lilypond -o public/samples/groove samples/groove.ly` で PDF を再生成)。
`tests/fixtures/` の PNG は同じ譜面を画像化したもので、認識結果を正解と照合しています。

`dev/align.html` と `dev/score.html` は録音の時刻合わせと採点を検証するページです
(`npm run dev` で開き、決まった時刻に鳴らした音を録音経路に流して、検出時刻のずれを表示します)。

### 構成

```
src/
  main.js            画面とイベント処理 (ホーム / PDF / 作成モード)
  grid.js            作成モードのマス目入力
  library.js         作った譜面の保存 (localStorage)
  game/game.js       ゲーム画面 (フレーズ一覧・練習・録音・採点・成長の記録)
  game/presets.js    練習用フレーズ集
  game/shift.js      フレーズを音符単位でずらす
  game/recorder.js   マイク録音 (採点用 PCM と聞き返し用ファイル)
  game/onsets.js     録音から打音 (アタック) を検出
  game/scoring.js    採点・遅延の推定
  game/takes.js      録音の保存 (IndexedDB) と経験値・レベル
public/worklets/capture.js  マイク入力を AudioContext の時刻つきで取り出す AudioWorklet
  notation/tokens.js 音符の並びを楽譜の音価・休符に変換
  notation/render.js VexFlow で楽譜を描画
  pdf.js             pdf.js による描画・テキスト読み取り・解析の呼び出し
  drums.js           楽器定義と、五線上の位置 → 楽器の対応表
  omr/analyze.js     画像から五線・小節線・符頭を検出 (Web Worker で実行)
  omr/rhythm.js      符頭の間隔から拍位置を推定 (動的計画法)
  omr/buildScore.js  解析結果から譜面データを組み立てる
  audio/sampler.js   生ドラムのサンプル音源 (public/sounds/virtuosity)
  audio/synth.js     合成音 (サンプル読み込み前の予備とメトロノーム)
  audio/sequencer.js テンポ・ループ・カウントインを扱うシーケンサー
  audio/player.js    シーケンサーを AudioContext 上で鳴らす
```

## 音源について

`public/sounds/virtuosity/` は Versilian Studios / Karoryfer Lecolds の
[Virtuosity Drums](https://github.com/sfzinstruments/virtuosity_drums) (CC0 1.0) から
楽器ごとに 2 テイクずつ抜き出し、キック・スネア・オーバーヘッドの各マイクをミックスして MP3 にしたものです
(合計 約 860KB)。バスドラムはスマホのスピーカーでも聞こえるよう中音域を強調した版も用意しています。
メタル向けのバスドラムは `public/sounds/bja-pacific/` (BJA Pacific drumkit を EQ 加工、CC BY-SA 3.0 US) で、設定パネルの「バスドラムの音色」で選べます。詳細は同フォルダの README.md を参照してください。

## 公開 (GitHub Pages)

`main` ブランチに push すると `.github/workflows/deploy.yml` がビルドして GitHub Pages に公開します。
初回はリポジトリの Settings → Pages → Source を「GitHub Actions」にしてください。
